### 🎬 導入

This 35B model is near frontier on multiple different benchmarks. It's called Apoex 1.1 Mini and it achieves this by using Frontier Agent, a new open-source harness. Now, here's what I learned from studying Frontier Agent. The agents run like a research team. You give it a task and the coordinator splits the work across multiple agents.

### 📋 背景・概要

Some search the web, others read the data, and other agents run the analysis code. This allows you to run more agents without losing control. Another clever trick that Frontier Agent uses is that only one agent is ever responsible for writing the final report. Just like in a human team, every outcome needs one clear owner, so there's no confusion. Another clever design of Frontier Agent is that the agents don't need every single tool result loaded in the context at once.

### ⭐ 主要ポイント

That's because Frontier Agent keeps those results in a run log and lets agents retrieve the specific sections when they need them. This saves space in the context window and reduces memory usage, which is especially useful if you're running it locally. So, if you're building research agents, you should definitely explore Frontier Agent. It's completely free and open source. Just give it a star on GitHub.
