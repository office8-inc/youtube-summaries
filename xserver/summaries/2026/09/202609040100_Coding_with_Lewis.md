- grill with docs — 「grill me」をさらに一歩進めたもので、コードベースの用語や設計についてコーディングエージェントと認識を統一する。2日に1回くらいの頻度で走らせるとよい。  
- caveman — エージェントに短く簡単な言葉で話させるスキル。大規模言語モデルはアシスタントとして訓練されているぶん、特に何かを届けようとするときに冗長になりがちなので、その逆を行くことでトークンを大きく節約できる。  
- deepgram transcribe — 投稿者自身が作ったスキル。音声ファイルやURLを受け取り、クラウドサービスで話者名と説明付きに書き起こす。Whisperでも使え、スピーチを分解して読み解くのに向く。  
- two tickets（Matt Pocock作） — 巨大なプロジェクトを丸ごと投げるのではなく、扱いやすい小さなサブタスクに分割するスキル。分けたぶんを複数のエージェントに分散できる。  
- agent browser — Chromeを使ってWeb上の操作を行う。Webアプリケーションや、作っているならElectronアプリのデバッグにも使える。
