## ⭐ 重要なポイント

- Jev は与えた選択肢に確率を割り振る意思決定モデル。「敵の体力が低い、どうする？」に対して attack 25%、retreat 15%、take cover 60% のように返し、コード側が最高確率の行動を選ぶ。信頼度スコアも付くが、50%ならコイン投げと変わらない点は投稿者も釘を刺している。  
- サンプリングが逐次ではなく並列で、エンドツーエンドの応答時間は70〜500ミリ秒。同水準のモデルと比べて40〜200倍速いとされ、それがゲームのようなリアルタイム用途で効いている。  
- スポーツブックの実験では、Chelsea 対 Brentford で João Pedro の出場が不透明というニュースを投入。「この負傷ニュースは Chelsea の勝利に関係があるか」には yes（先発ストライカーだから）、「価格に影響するか」には yes 80% という答えが返った。  
- 実際には Pedro は先発せず、それでも Kalshi の価格はほとんど動かなかった。噂が広く出回っており既に織り込まれていたためで、シミュレーション上は38.5から35へ下がる想定だった。  
- Bitcoin の板を使った実験もあり、「板の方向性圧力は構造的に支持されているか」には72、「表示流動性はどれだけ脆いか」には bilateral thinness、「市場は過小反応しているか」には under expressed といった答えを返した。  
- 価格は100万トークンあたり入力0.042ドル、出力は無料でほぼタダ同然。OpenRouter 経由でテストしており、当面はシャドーとペーパーモードで検証を続けるとしている。Kalshi の API と Pinnacle のサッカーデータと Jev を繋いだストリーミングも作ったが、こちらは価値を見出せなかった。
